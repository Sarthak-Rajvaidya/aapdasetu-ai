Under the hood

Built as a real full-stack platform

AapdaSetu combines a web frontend, API backend, database, authentication, machine learning and AI-assisted retrieval.

Frontend

HTML5, CSS3, JavaScript and Bootstrap-based responsive interfaces.

Backend

FastAPI and Python with modular API routers and service-layer architecture.

Database

SQLAlchemy-backed persistence with local SQLite and PostgreSQL-ready configuration.

AI / RAG

Retrieval-based disaster knowledge assistance designed to ground responses in safety information.

Machine Learning

Scikit-learn based risk-awareness and environmental prediction workflows.

Authentication

JWT-based authentication with password hashing and protected API routes.

Important: AapdaSetu AI is an educational preparedness and training platform. It is not a replacement for emergency services or official government guidance. During a real emergency, follow instructions from local authorities and emergency services.
